{{- /* Fenced code block render hook. Same output as Hugo's default, plus two additions. First, a run of code wrapped in ⟦ and ⟧ renders inside , so a post can highlight part of a line where `hl_lines` would take the whole line. Second, each line carries its indent (see the end of this comment). A marker usually gets a Chroma span of its own, but a lexer may glue it to a neighboring operator, as Lean's does with `↔⟧`. So the span holding a marker is split at the marker, and the mark tag goes between the halves. That nests cleanly as long as both markers sit on the same line. Empty halves are removed afterwards. The markers themselves never reach the page. The tags are styled in assets/css/code.scss. `.Inner` drops the trailing newline that the default renderer keeps, so it is put back to leave every block without markers byte-identical to before. `.Options` carries the fence attributes such as `hl_lines`. Each line also gets its leading indent, in spaces, as the `--indent` custom property. On a narrow screen assets/css/code.scss soft-wraps long lines and uses it to indent the wrapped part under the line it belongs to. Chroma puts the leading spaces of a line in a whitespace span of their own, right after the line's opening tags. */ -}} {{- $html := highlight (printf "%s\n" .Inner) .Type .Options -}} {{- $html = replaceRE `([^<]*)⟦([^<]*)` `$2$3` $html -}} {{- $html = replaceRE `([^<]*)⟧([^<]*)` `$2$3` $html -}} {{- $html = replaceRE `` `` $html -}} {{- $lineStart := `` -}} {{- $parts := split $html $lineStart -}} {{- $out := index $parts 0 -}} {{- range after 1 $parts -}} {{- $indent := 0 -}} {{- with findRESubmatch `^( +)` . 1 -}} {{- $indent = len (index (index . 0) 1) -}} {{- end -}} {{- $out = printf `%s%s` $out $indent . -}} {{- end -}} {{- $out | safeHTML -}}
